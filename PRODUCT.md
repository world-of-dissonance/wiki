# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

- Players during a session: quick lookups mid-game (a skill, a condition, a rule), often on a phone or a second screen beside Minecraft.
- Players before they join: reading lore, choosing a race and variant, and building a character at their own pace.
- The DM: checking rules and stat systems while running combat.
- The doc's author: the wiki is a surprise gift to them; it should feel like their world presented properly for the first time.

## Product Purpose

The World of Dissonance wiki turns the setting's single long Google Doc (lore, peoples, aspects, Arcana, skills, rules) into a searchable, navigable website for a Minecraft TTRPG. Success: players find any rule or skill in seconds, and the world reads as a place worth exploring.

## Positioning

It is the doc itself, live: every page is rebuilt hourly from the author's Google Doc, so the wiki never drifts from the source and nobody maintains it by hand.

## Operating Context

- Static site on GitHub Pages (world-of-dissonance.github.io/wiki), generated by `build.py` from the doc's anonymous Markdown and HTML exports; an hourly GitHub Action redeploys on change.
- Companion tools share the setting: the in-game character sheet mod (Forge 1.20.1) and the web character maker (world-of-dissonance.github.io/wod-character-maker).
- Played in Minecraft sessions; readers switch between the game and the wiki.

## Capabilities and Constraints

- One page per doc tab (20 today; three item catalogs are still empty and show as coming soon); headings become each page's contents.
- Full-text search over every section; pictures from the doc, grouped as sideways strips when several sit together; skill trees as tables.
- Read-only toward the doc: nothing ever writes back to it.
- Kept out of search engines until the reveal (`HIDDEN` in build.py).
- Content is the author's own wording, typos included; the wiki does not edit it.
- Terminology: Tantalos, Aeode, Lychgate, Vibrae-Kin, aspects (Astra, Fibero, Eternum), Arcana (Wonder, Will, Weapon), signatures (Affix, Animus, Afflatus, Ability), skill trees with T1/T2/T3 tiers, Core/Shell/Essence.

## Brand Commitments

- Name: World of Dissonance. The user is open to a fully different visual world for the wiki as long as all content and features stay.

## Evidence on Hand

- The doc's text and its pictures (race art, Daemon examples, Lychgate build references).
- Sheet art from the mod: `wod-charsheet/src/main/resources/assets/wod_charsheet/textures/gui/sheet/` (background, crescents).
- No player counts, testimonials or external claims exist; none should be invented.

## Product Principles

- The doc is the source of truth; the wiki presents, never rewrites.
- Lookup speed matters as much as atmosphere: a rule mid-session must be two taps away.
- Long lore pages and dense skill trees must be easy to scan.
- The world should feel specific to Tantalos, not like a generic docs theme.
